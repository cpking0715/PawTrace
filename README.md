# PawTrace 🐾

**PawTrace（爪印）** 是一款面向狗狗家长的遛狗记录与汪友社交应用原型。以「崽崽」（狗狗）为主体视角，记录遛狗轨迹、发现撒欢地、结识附近玩伴，并在崽崽圈里晒出每一次开心的遛弯。

> 当前仓库为 **纯前端交互 Demo**：无后端、无持久化，数据均为内存态模拟，用于验证产品设计与交互流程。

---

## ✨ 核心功能

应用共 5 个 Tab：

| Tab | 功能 |
|---|---|
| 🗺️ 地图 | 基于 Leaflet 的周边地图：狗狗实时定位、热力图（遛狗热点）、公园标记、附近玩伴 |
| 🌳 撒欢地 | 遛狗好去处列表与详情（评分/设施/距离），支持标记新地点（悬浮按钮吸附底部） |
| 🐕 遛弯 | 遛狗全流程：多狗选择 → 实时遛狗页（轨迹采样/计时/距离）→ 崽崽战报（轨迹地图+统计） |
| 🐾 崽崽圈 | 仅玩伴可见的私域时间线：晒崽崽、拍爪互动、遛弯战报一键晒圈 |
| 🏠 崽崽家 | 崽崽档案（多狗管理/年龄/颜色/喜好/脾气/体重）、玩伴管理、定位权限「崽崽在哪」设置 |

### 崽崽社交体系

- **地图玩伴标记**：附近玩伴崽崽以弹跳光环标记展示并持续游走，点击查看崽崽信息；陌生汪带碰爪引导
- **碰个爪**：与陌生汪互碰成为玩伴，玩伴关系实时同步到崽崽圈可见性
- **崽崽战报**：遛狗结束后生成轨迹回放地图、时长/距离/大卡统计，支持一键晒到崽崽圈
- **崽崽手账**：每一次遛弯自动入册，可回看历史
- **多狗遛狗**：支持一次选多只崽崽出门，档案独立维护

## 🚀 快速开始

无需安装依赖，用任意静态服务器打开 `demo/` 目录即可：

```bash
# Python
python -m http.server 8090 --directory demo

# 或 Node
npx serve demo
```

然后浏览器访问 `http://localhost:8090`。

> 建议使用移动端视口（如 390×844）体验，页面按手机尺寸设计。

## 🛠️ 技术栈

- **原生前端**：HTML / CSS / JavaScript（无框架、无构建）
- **地图**：[Leaflet 1.9.4](https://leafletjs.com/) + leaflet.heat（热力图插件）
- **设计令牌**：CSS Variables 统一管理配色与间距

### 配色体系：奶油杏橙 🍑

整体采用暖色奶油杏橙主调，更暖更可爱：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--c-primary` | `#EE9B58` | 主色（按钮/强调） |
| `--c-primary-dark` | `#D9843F` | 主色加深 |
| `--c-primary-light` | `#FDF1E4` | 主色浅底 |
| `--c-peach` | `#F4A698` | 蜜桃粉辅助色 |
| `--c-gold` | `#F7C873` | 暖阳金辅助色 |
| 页面底色 | `#FBF8F5` | 暖米白背景 |
