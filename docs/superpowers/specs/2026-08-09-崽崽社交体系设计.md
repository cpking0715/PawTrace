# 崽崽社交体系设计文档

> 碰个爪交玩伴 · 崽崽圈 · 地图玩伴标记 · 崽崽战报 · 撒欢地增强
>
> 日期：2026-08-09 ｜ 状态：已与用户逐节确认 ｜ 方案：方案 A（高保真沉浸演示）

## 1. 背景与目标

PawTrace（狗遇）是纯前端遛狗热力图 Demo（无后端、内存数据、无持久化）。本轮为产品注入社交灵魂，让"遛狗相遇"变成"狗友相识"：

1. **碰个爪交玩伴**：两台手机碰一碰即加狗友；定位权限默认仅玩伴可见，支持三级控制与逐位单独开关
2. **崽崽圈**：仅玩伴可见的朋友圈，只能拍爪（点赞），无评论无聊天
3. **地图玩伴标记**：玩伴的崽崽在地图上有弹跳特效 + 光环，一眼可辨
4. **崽崽战报**：遛弯结束输出统计（时长/距离/大卡/轨迹），一键晒到崽崽圈，记录保留（为后续地图点亮预留）
5. **撒欢地增强**：现有地点页加搜索框 + 宝藏遛狗圣地标记（不另设独立推荐区，与现有地点推荐合一）

所有功能以预置虚拟数据在单机内完整演示。

## 4. 整体架构

### 4.1 导航与页面结构

底部 Tab 扩为 **5 个**：`地图 · 撒欢地 · 遛弯 · 崽崽圈 · 崽崽家`（遛弯居中突出，崽崽圈插在崽崽家前，原 4 Tab 位置零改动）。

新增 / 落地的页面与浮层：

| 页面/浮层 | id | 入口 | 职责 |
|------|------|------|------|
| 崽崽圈 | `pageCircle` | Tab「崽崽圈」 | 动态时间线、拍爪、晒崽崽 |
| 玩伴列表 | `pageFriends` | 「崽崽家」菜单「玩伴」+ 碰个爪后 | 定位开关、遛弯状态、删除、查看档案 |
| ta 家崽崽 | `pageFriendDetail` | 玩伴列表点击 | 查看玩伴的崽崽档案（不含定位） |
| 小窝设置 | `pageSettings` | 「崽崽家」菜单「设置」（落地现占位项） | 「崽崽在哪」三级控制 |
| 崽崽战报 | `pageWalkSummary` | 确认结束遛狗后 | 轨迹地图 + 统计 + 一键晒圈 + 存入手账 |
| 崽崽手账 | `pageWalkRecords` | 「崽崽家」菜单「遛狗记录」（落地现占位项） | 历史遛弯记录列表 |
| 碰个爪浮层 | `bumpOverlay` | 地图页悬浮按钮 + 玩伴页「碰个爪」 | 全屏相遇动画（非独立页） |
| 撒欢地搜索+宝藏标记 | 页内 | 「撒欢地」页 | 搜索实时过滤 + 宝藏地点卡片标记（不另设独立推荐区） |

「崽崽家」页菜单调整：新增「玩伴」菜单项（带数量 badge），与「家里崽崽」并列；「遛狗记录」→「崽崽手账」；「设置」→「小窝设置」；个人称号「遛狗达人」→「崽崽家长」。

### 4.2 数据模型（纯前端内存数据，延续 `app.js` 现有风格）

**候选玩伴池 `dogFriendsPool`**（可被碰个爪发现 / 地图上开放定位的陌生汪）：

```js
{
  id, name, avatar,               // 玩伴本人（名字 + 头像 emoji）
  dogs: [{ name, emoji, breed, size, age, color, tags }],  // ta 的崽崽（复用狗狗档案字段）
  isWalking: true/false,          // 是否正在遛弯（决定地图是否显示其崽崽）
  loc: { lat, lng },              // 模拟位置（城市中心附近）
  openToAll: true/false,          // 是否"对所有人开放定位"
  posts: ['p1', 'p2'],            // ta 在崽崽圈的动态 id（成为玩伴后可见）
}
```

预置 4~5 位候选：其中 1~2 位 `isWalking: true`（地图可见/碰个爪优先发现）、1~2 位 `openToAll: true`（陌生汪演示）、其余在家休息。

**我的玩伴 `myFriends`**（从池中碰个爪添加而来）：

```js
{ ...池字段, shareMyLocTo: true }   // 我是否对 ta 开放我的崽崽行踪（单独开关，默认 true）
```

**我的定位隐私 `myLocationPrivacy`**：

```js
{ mode: 'friends' }   // 'friends'(默认,仅玩伴可见) | 'everyone'(所有汪星可见) | 'off'(关闭行踪)
```

**崽崽圈动态 `circlePosts`**：

```js
{ id, authorId,               // 'me' 或玩伴 id
  authorName, authorAvatar, dogName, dogEmoji,
  cover: { gradient, emoji }, // 纯前端无真实图片：预设渐变色块 + 崽崽大 emoji 模拟配图
  text, time, likes: n, likedByMe: false,
  type: 'normal' | 'walkReport',   // walkReport = 崽崽战报动态
  stats: { duration, distance, calories }  // 仅 walkReport 类型
}
```

**遛弯记录 `walkRecords`**（每次结束遛狗追加，保留；崽崽手账数据源，为后续地图点亮预留）：

```js
{ id, date, duration, distance, calories,
  track: [{lat,lng}, ...],    // 本次轨迹点
  dogs: [{name, emoji}],      // 本次一起遛的崽崽
  published: false }          // 是否已晒到崽崽圈
```

**`walkState` 扩展**：遛狗中持续采样 `track: [{lat,lng}]`（模拟移动定时器中记录狗标记坐标），结束时据此绘制轨迹并计算大卡。

**地点 `spotsData` 扩展**（支持搜索+宝藏标记，仍为单一列表）：

```js
{ id, name, distance, note, rating,
  isTreasure: true/false,     // 是否"宝藏撒欢地"
  treasureReason,             // 推荐理由
  hot,                        // 热度（如 "本周 128 只崽崽来过"）
  tags: [] }                  // 特色标签（大草坪/有围栏/可脱绳…）
```

**可见性逻辑**（核心规则）：

- 我能否看到对方崽崽 = 对方 `isWalking` 且对方对我开放（玩伴默认互开；陌生汪需 `openToAll`）
- 对方能否看到我 = 我的 `myLocationPrivacy.mode` + 该玩伴位 `shareMyLocTo`（demo 中以数据标记模拟，体现在提示文案与玩伴卡片状态上）
- 崽崽圈只渲染 `authorId ∈ myFriends` 或 `authorId === 'me'` 的动态

## 5. 功能设计

### 5.1 碰个爪（`bumpOverlay` 全屏浮层）

**入口**：地图页右上悬浮按钮「🐾 碰个爪」（与定位/筛选并列）＋ 玩伴列表页顶部按钮。

**交互流程**（单机模拟，自动发现预置候选）：

1. **靠近**：暗色聚光浮层，两个爪印图标从两侧向中间靠拢（缓动动画）
2. **雷达扫描**：波纹自中心扩散 + 文案「正在感受附近的崽崽…」
3. **发现**：从 `dogFriendsPool` 取一位**非玩伴**候选（优先 `isWalking: true`，随机），弹出对方卡片：头像、名字、ta 家崽崽（emoji+名字+品种）、距离文案
4. **确认**：点「碰个爪，交玩伴」→ 爪印/撒花成功动画 → 写入 `myFriends`（`shareMyLocTo: true`）→ 提供「看看 ta 家崽崽」（跳档案页）与「继续碰碰」两个后续
5. **边界**：候选耗尽 → 提示「附近暂时没有出来遛弯的玩伴，去别处逛逛吧～」；点遮罩/关闭可退出浮层

### 5.2 玩伴管理（`pageFriends`）

- 顶部：标题「玩伴」+ 数量 +「碰个爪」按钮
- 每张玩伴卡片：
  - 头像 + 名字 + ta 家崽崽（emoji + 名字）
  - **遛弯状态**：正在遛弯（绿点脉冲动画）/ 在家休息（灰点）
  - **定位开关**「让 ta 看见我家崽崽」toggle（单独控制 `shareMyLocTo`，默认开）
  - 点击卡片主体 → `pageFriendDetail` 查看 ta 家崽崽档案；卡片操作 → 删除玩伴（确认弹窗，从 `myFriends` 移除，其崽崽圈动态随之不可见）
- 空状态：「还没有玩伴，去碰个爪认识新朋友吧～」+ 碰个爪按钮

**ta 家崽崽（`pageFriendDetail`）**：展示玩伴的每只崽崽档案（头像/名字/品种·体型·年龄·体重/毛色/脾气/喜好/疫苗），**不含定位信息**，风格复用狗信息卡。

### 5.3 定位权限（`pageSettings` →「崽崽在哪」）

- **三级单选**（控制「我的崽崽行踪被谁看到」）：
  - 仅玩伴可见（**默认**）｜ 所有汪星可见（对所有人开放）｜ 关闭行踪（全关）
  - 每级配说明文案解释含义
- **单独管理**：引导至玩伴列表逐位开关「让 ta 看见我家崽崽」
- 设置即时生效（写入 `myLocationPrivacy`），demo 中通过玩伴卡片状态文案与地图标记逻辑体现

### 5.4 地图玩伴标记

在现有地图（热力图/公园标记/自己遛狗标记）之上叠加两类个体标记：

- **玩伴的崽崽**（`myFriends` 中 `isWalking: true`）：
  - 狗狗 emoji 头像 + **上下弹跳动画** + **玩伴光环**（主题色光圈描边，脉动），一眼区分
  - 位置在 `loc` 附近缓慢随机移动（模拟遛弯）
  - 点击 → 弹「ta 家崽崽」档案卡（复用底部信息卡样式，头部加「玩伴」徽章）
- **开放定位的陌生汪**（池中 `openToAll: true` 且 `isWalking: true` 且非玩伴）：
  - 普通样式（无弹跳无光环）狗狗 emoji 标记
  - 点击 → 简卡（崽崽名+品种）+「碰碰爪交个玩伴」引导按钮（打开碰个爪浮层并定位到该候选）
- zIndex 分层：玩伴标记 > 陌生汪标记 > 自己遛狗标记，不与热力图/公园标记冲突

### 5.5 崽崽战报与崽崽手账

**崽崽战报（`pageWalkSummary`）**：

- **触发**：结束遛狗确认弹窗点「确认结束」→ 进入战报页（不再只是关闭弹窗）
- **轨迹地图**：Leaflet 绘制本次 `walkState.track` 轨迹线（主题色）+ 起点/终点标记
- **统计卡片**：遛弯时长 · 移动距离 · 消耗大卡 · 一起遛的崽崽头像排
  - 大卡估算：`calories ≈ Σ(崽崽体重kg) × 距离km × 1.2`（演示用粗略公式）
- **「晒到崽崽圈」**：一键生成 `type: 'walkReport'` 动态（轨迹缩略 + 统计摘要），可附加一句话后发布；该记录 `published: true`
- **「存入手账」**：写入 `walkRecords`（无论是否晒圈都保存）；提供返回地图按钮

**崽崽手账（`pageWalkRecords`）**：历史遛弯记录列表（日期/时长/距离/大卡/崽崽），点击可回看战报详情（复用战报页渲染指定记录）。本期不做地图点亮可视化，数据已预留。

### 5.6 撒欢地增强（搜索 + 宝藏标记，与现有地点推荐合一）

> 现有「撒欢地」页本就是附近遛狗圣地推荐（4 个友好地点卡片），因此**不另设独立「宝藏推荐区」**，宝藏圣地直接融入现有列表。

- 页顶部新增**搜索框**：实时过滤 `spotsData`（匹配名称/备注/标签），无结果显示「没找到相关撒欢地」空状态
- 现有地点卡片上为 `isTreasure: true` 的地点加**「💎 宝藏」角标**，卡片内追加展示：推荐理由、热度、特色标签；宝藏卡片带轻微视觉突出（描边/渐变底色），一眼可辨
- 卡片点击交互保持现状：切到地图并定位到该地点（flyTo + 弹地点卡）
- `spotsData` 调整：现有 4 个地点中挑 1~2 个标记为宝藏并补充理由/热度/标签字段，另新增 1~2 个宝藏地点（共 5~6 个）

### 5.7 崽崽圈（`pageCircle`）

**时间线渲染规则（仅玩伴可见）**：

- 只渲染 `authorId ∈ myFriends` 或 `authorId === 'me'` 的 `circlePosts`，按时间倒序
- 碰个爪加了新玩伴后，ta 的预置动态立即出现（直观演示"仅好友可见"）
- 无玩伴 → 空状态「还没有崽崽动态，去碰个爪交个玩伴吧～」

**动态卡片**：

- 发布者头像 + 名字 + 时间
- 封面：预设渐变色块 + 崽崽大 emoji（提供 4~6 套预设，纯前端模拟配图）
- 文案 + 互动区：**拍爪**按钮 + 数量；拍爪时爪印图标弹出动画（`likedByMe` 切换、计数 ±1）
- **无评论、无聊天**（严格按需求限定）
- **崽崽战报动态**（`type: 'walkReport'`）：专属模板——轨迹缩略图 + 时长/距离/大卡摘要，与普通图文卡视觉区分

**晒崽崽（发布）**：

- 入口：崽崽圈右上「晒崽崽」按钮
- 发布弹窗：选崽崽（家里崽崽头像）→ 选封面风格（预设渐变+emoji 组合）→ 输入文案 → 发布
- 发布后动态置顶出现在时间线

## 6. 边界与异常处理

| 场景 | 处理 |
|------|------|
| 碰个爪候选耗尽 | 提示「附近暂时没有出来遛弯的玩伴，去别处逛逛吧～」 |
| 无玩伴时的崽崽圈 | 空状态引导碰个爪 |
| 无玩伴时的地图玩伴标记 | 不渲染玩伴标记（陌生汪按 openToAll 独立判断） |
| 定位「关闭行踪」 | 数据层标记我对所有人不可见，玩伴卡片状态文案同步 |
| 删除玩伴 | 确认弹窗；移除后其崽崽圈动态不可见、地图标记消失 |
| 遛狗中切 Tab | 轨迹采样不中断（`walkState.track` 持续记录） |
| 搜索无结果 | 「没找到相关撒欢地」空状态 |
| 未选崽崽晒崽崽 | 发布按钮禁用/提示先选崽崽 |
